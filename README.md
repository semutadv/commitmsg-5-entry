A single commit message, written for the make.fun bounty "Worst Fix
Ever: Funniest Commit Message" — the message for a bug fix that made
everything worse. The memory leak is patched by deleting the part of
the app that remembers anything: the leak stops, technically, because
so does everything else. It reads exactly like a line from a real
repository history, which is where the irony lives.

## Running it

`node main.ts` clears the output directory's contents and writes the
commit line to `/output/entry.txt` as plain UTF-8 text.
